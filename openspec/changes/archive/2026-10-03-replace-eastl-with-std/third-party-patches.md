# Bundled integration patches

These are local Nau integration patches to retained third-party sources, not imported releases or replacement implementations. Original copyright and license headers remain in place.

- `NauEngineLite/engine/core/modules/ui/cocos2d-x`: retain Cocos2d-x and its existing MIT-style license. The prior Nau integration exposed EASTL strings in Cocos APIs. Those APIs and their callers now use `std::string`; printf-style string construction uses the existing `cocos2d::StringUtils::format` implementation. The logging macro retains its function-name prefix. The direct Cocos EASTL CMake link is removed. The Apple implementation is kept source-consistent; it is not executable on this Windows host. Native Debug `cocos2d`, `ui` and `Graphics` targets build with the migrated interfaces. No live EASTL includes or namespace references remain in UI/VFX/graphics source (historical AUTHORS text is retained).
- `NauEngineLite/engine/3rdparty_libs/ska_hash_map/ska_hash_map/flat_hash_map2.hpp`: retain Malte Skarupke's hash-table algorithm and Boost Software License 1.0 attribution. Replace the earlier Nau EASTL utility/allocation integration with standard utilities and typed allocator rebinding for aligned table entries. Unequal-resource moves and swaps transfer elements without exchanging allocation ownership. Heterogeneous lookup uses the table's hash/equality objects rather than hashing a character pointer as an address. The standalone `ska_hash_map` probe compiles without EASTL include directories and covers over-aligned owning values, growth, erase, copies, unequal-resource transfers, lookup and paired destruction/release.
- `NauEngineLite/engine/3rdparty_libs/ModifiedSonyMath`: retain its existing source and license, replacing the five Nau-added sphere/quad/bone helper signatures that took EASTL vectors with `std::vector`. The public interface no longer links or imports EASTL.
- `NauEngineLite/engine/3rdparty_libs/binPack2D`: retain the existing packing implementation and license, replacing vector signatures/storage and algorithm/limit helpers with standard equivalents. The target no longer links EASTL; its clients use the same rectangle requests and results.

The EASTL target and bundled source were retired in section 6. Installed-SDK auditing and dormant Dagor networking validation are recorded separately.

- `NauEngineLite/engine/3rdparty_libs/JoltPhysics/Jolt/Jolt.cmake`: keep Jolt's `_DEBUG` definition private to its own Debug compilation. Exporting it through the installed static Jolt target made downstream Release SDK consumers define `_DEBUG` and link against debug CRT symbols. Jolt itself retains the same per-configuration definition; the installed consumer now uses its own Release CRT settings.
